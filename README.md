# La Taperia

Site oficial da La Taperia — Tapas, Pintxos e Coquetelaria.

## Estrutura

- `index.html` — página principal
- `style.css` — estilos do site
- `README.md` — documentação do projeto
- `vercel.json` — configuração de publicação na Vercel

## Publicação

Este projeto é um site estático e pode ser publicado diretamente na Vercel ou no GitHub Pages.

### Vercel

Importe o repositório no Vercel e mantenha a configuração padrão para um projeto estático.

Não é necessário executar `npm install`, `npm run build` ou qualquer outro comando de build.

## Observação

O `index.html` utiliza `style.css` na mesma pasta e também possui referências externas para Google Fonts, Google Maps, WhatsApp e Instagram.
